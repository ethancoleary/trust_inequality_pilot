Intro

During this study, you will complete as many exercises of a task as you can in 2 minutes. The task has been selected to ensure that a good score requires solely hard effort and relies little on pre-existing skills.

For every exercise that you successfully complete, you will earn a bonus of £0.05.

The Task

In each exercise you will need to decrypt a set of letters. You will observe a code, decryption key, and an empty text box.

The code contains 5 letters. For each letter, you need to find the corresponding decrypted letter using the decryption key and then type this letter in the empty text box.

Once you believe that you have successfully decrypted the code and typed it into the text box, you should click on 'Submit'. If your decryption is correct, then a new exercise will appear and your score will increase by 1.
